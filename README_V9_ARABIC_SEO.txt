GÖCEK TWIN VILLAS - V9 ARABIC SEO

Bu paket V8 çerez onayı + Google Analytics + Microsoft Clarity yapısını korur.
Sadece Arapça /ar/ sayfasının SEO metinleri güçlendirilmiştir.

Güncellenen ana hedefler:
- فلل للبيع في تركيا
- فلل للبيع في فتحية
- فيلا للبيع في غوجيك
- شراء عقار في تركيا
- فيلا مع مسبح خاص

Güncellenen alanlar:
- title
- meta description
- Open Graph / Twitter SEO alanları
- WebPage JSON-LD name/description
- H1
- hero açıklaması
- Arapça pazar/SEO bölümü

YÜKLEME:
ZIP'i açın ve içindeki dosya/klasörleri GitHub repo ana dizinine yükleyip Commit changes yapın.
Mevcut CNAME, Yandex doğrulama dosyası ve IndexNow anahtar dosyasını silmeyin.

Yüklemeden sonra yalnızca /ar/ sayfası güncellendiği için:
- Google Search Console: /ar/ için Request Indexing
- Bing/IndexNow: /ar/ URL'sini bir kez yeniden gönder
- Yandex: /ar/ sayfasını Reindex queue'ya bir kez ekle
