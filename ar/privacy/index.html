1. الجهة المسؤولة

يُدار هذا الموقع (gocektwinvillas.com) من قبل مالك العقار لعرض فيلتين للبيع في غوجيك / إنليجه (فتحية، موغلا، تركيا). لأي طلب يتعلق بالخصوصية: elitvillasingocekinlice@gmail.com

2. ما البيانات التي نعالجها؟

  • بيانات التواصل: الاسم ورقم الهاتف والبريد الإلكتروني ومحتوى الرسالة التي تشاركها معنا عبر واتساب أو البريد الإلكتروني أو الهاتف. نستخدمها فقط للرد على طلبك ومتابعة مفاوضات البيع.
  • بيانات الزيارة (بموافقتك فقط): الصفحات التي تم عرضها ومعلومات الجهاز والمتصفح والموقع التقريبي والتفاعل مع الموقع، ومع Clarity تسجيلات الجلسات والخرائط الحرارية، عبر Google Analytics وMicrosoft Clarity.
  • سجلات الخادم: يُستضاف الموقع على GitHub Pages، وقد تعالج GitHub سجلات تقنية مثل عناوين IP لأغراض أمان البنية التحتية.

3. ملفات الارتباط والتحليلات

تظهر عند أول زيارة نافذة لاختيار ملفات الارتباط. لا يتم تحميل Google Analytics وMicrosoft Clarity، ولا تُضبط ملفاتهما (مثل _ga و_clck و_clsk)، إلا بعد الضغط على «قبول». يُحفظ اختيارك في التخزين المحلي للمتصفح (gtv_consent_v1)، وهو ضروري لعمل الموقع. لا نستخدم ملفات ارتباط إعلانية.

يمكنك تغيير اختيارك في أي وقت عبر زر «إعدادات ملفات الارتباط» في زاوية الصفحة.
